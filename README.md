# つかみやすいスクロールバー

Vivaldi用の拡張機能です。Google スプレッドシートでは、右端の縦バーと下端の横バーを12pxから24pxに広げます。広くなった部分からもつまみをドラッグできます。

## インストール

1. [最新版のリリース](https://github.com/cac-gwd/wide-scrollbars/releases/latest)から `WideScrollbars.zip` をダウンロードします。
2. ZIPを、拡張機能を使う間は移動・削除しないフォルダーに展開します。
3. Vivaldiのアドレスバーに `vivaldi://extensions` と入力し、「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開した中の `manifest.json` が直接入っている `WideScrollbars` フォルダーを選びます。
5. 開いているスプレッドシートやウェブページを再読み込みします。

リポジトリをクローンした場合も、手順4で `WideScrollbars` フォルダーを指定します。ビルドは不要です。元に戻すには、拡張機能をオフにしてページを再読み込みしてください。

## 一般サイトでの動作と権限

一般のHTTP・HTTPSページでは、ブラウザ標準のスクロールバーの太さを測り、その2倍を設定します。重ねて表示されるバーなど、太さを測れない場合は24pxを使います。サイトが独自に描画するバーやブラウザの設定ページは対象外です。

一般サイトでも自動で適用するため、HTTP・HTTPSページにスタイルと計測用スクリプトを適用する権限を使います。スプレッドシートには専用のCSSを適用します。拡張機能によるセル内容の読み取り、データの保存、外部への送信はありません。

## 動作確認

WindowsのChromium版Edgeで、Googleの公開サンプルシートの縦・横のバーを広げた部分からドラッグできることと、下部のシートタブにアクセスできることを確認しました。一般ページのテストでは縦・横のバーが15pxから30pxに広がり、両方向にドラッグできました。Vivaldi本体では未検証です。
