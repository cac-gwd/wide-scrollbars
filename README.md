# つかみやすいスクロールバー

Vivaldi用の拡張機能です。Google スプレッドシートでは、右端の縦バーと下端の横バーにマウスが近づくと、12pxから24pxに広がります。広くなった部分からもつまみをドラッグできます。

## スプレッドシートでの自動拡大（v1.2.0）

通常は元の太さで表示し、マウスがバーの約25px手前に来ると、そのバーを太くします。ドラッグ中は太さを維持します。バーの外端から56pxより離れると、0.35秒後に元の太さに戻ります。バーをシートの内側に広げるため、拡大中は端のセルの一部に重なります。

v1.3.0から一般サイトでも自動拡大を利用できます。初期設定は「マウスが近づいたときだけ」です。v1.3.1では、拡張アイコンをクリックして「太くするタイミング（このサイト）」を選ぶと、表示中のサイトの設定として保存されます。たとえばスプレッドシートは「常に太くする」、Twitchは「マウスが近づいたときだけ」にできます。旧版で選んだ共通設定は、まだ個別設定していないサイトの初期値として引き継ぎます。

## インストール

1. [最新版のリリース](https://github.com/cac-gwd/wide-scrollbars/releases/latest)から `WideScrollbars.zip` をダウンロードします。
2. ZIPを、拡張機能を使う間は移動・削除しないフォルダーに展開します。
3. Vivaldiのアドレスバーに `vivaldi://extensions` と入力し、「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開した中の `manifest.json` が直接入っている `WideScrollbars` フォルダーを選びます。
5. 開いているスプレッドシートやウェブページを再読み込みします。

リポジトリをクローンした場合も、手順4で `WideScrollbars` フォルダーを指定します。ビルドは不要です。元に戻すには、拡張機能をオフにしてページを再読み込みしてください。

## 一般サイトでの動作と権限

### サイトごとのオン・オフ（v1.1.0）

初期状態はオンです。たとえばTwitchを開き、ツールバーの拡張アイコンを左クリックして、設定画面の「このサイトで使う」をオフにすると、そのサイトだけ元の太さに戻り、アイコンに OFF と表示されます。同じチェックをオンにすると再び有効になります。アイコンが隠れている場合は、拡張機能メニューから表示・固定してください。

設定はこのブラウザのプロファイルに保存され、同じサイトの開いているタブにも再読み込みなしで反映されます。次回そのサイトを開いたときも設定は有効です。判定はホスト名単位で、先頭の `www.` は区別しません。たとえば `twitch.tv` と `www.twitch.tv` は共通、`dashboard.twitch.tv` は別設定です。

旧版から手動で更新する場合は、元と同じ拡張フォルダーに最新版を上書きし、`vivaldi://extensions` で拡張の再読み込みボタンを押してから、開いているページを再読み込みしてください。

一般のHTTP・HTTPSページでは、ページ端とページ内のスクロール欄で、ポインターがバーの外端から40px以内に来ると拡大します。60pxより離れて0.35秒後に元に戻ります。拡大時はブラウザ標準の太さの2倍、太さを測れない場合は24pxを使います。サイト独自のバー、Shadow DOM内のバー、ブラウザ設定ページは対象外です。一般サイトでは幅の変化で文章の折り返しなどが変わる場合があります。「常に太くする」も選択できます。

一般サイトでも自動で適用するため、HTTP・HTTPSページにスタイルとスクリプトを適用します。アイコンのクリック時に現在のタブのURLを参照し、オフにしたホスト名と表示モードをブラウザ内に保存します。スプレッドシートでは専用のCSSを使います。拡張機能によるセル内容の読み取りや外部への送信はありません。

## 動作確認

WindowsのChromium版Edgeで、Googleの公開サンプルシートの縦・横のバーに近づくと拡大し、広げた部分からドラッグでき、離れると元に戻ることを確認しました。下部のシートタブにもアクセスできます。一般ページのテストでは縦・横のバーが15pxから30pxに広がり、両方向にドラッグできました。Vivaldi本体では未検証です。
